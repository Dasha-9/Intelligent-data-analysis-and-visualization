# Данные

Файлы в репозиторий не загружаются. Положите сюда из комплекта практики 3.7 (`IAVD_3.7_ML_team/course_pack/`):

- `cards_practice.csv` – 320 карточек практики (40 наборов × 8), оценка и исход;
- `shap_cards.csv` – вклады 73 признаков по каждой карточке, base, proba;
- `cards_raw.parquet` – исходные поля карточек (значения в таблице вкладов и поля карточки).

`python/local_shap.py` читает модель и эти файлы прямо из папки комплекта – путь к ней передаётся аргументом.
