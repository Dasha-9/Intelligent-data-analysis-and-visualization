# Данные

Файлы датасета в репозиторий не загружаются (см. `.gitignore`): полный parquet весит ~174 МБ, а GitHub не принимает файлы больше 100 МБ; кроме того, в данных есть имена хостов и учётных записей.

Положите сюда локально:

| Файл | Для чего |
|---|---|
| `iavd_1000_incidents_raw_target.parquet` | выборка 1000 карточек — эскиз (`python/sketch_matplotlib.py`) |
| `iavd_incidents_raw_target.parquet` | полный датасет 240 295 карточек — панель Taipy и Qlik |

Файлы берутся из материалов курса.
